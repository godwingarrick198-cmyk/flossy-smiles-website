# Flossy Smiles Dental Implants & Aesthetics

Premium static website concept for Flossy Smiles in Coral Gables.

## Pages
- /
- /dental-implants.html
- /cosmetic-dentistry.html
- /about.html
- /patient-information.html
- /contact.html
- /404.html

## Deployment
Deploy the project root to Netlify with:
- Build command: blank
- Publish directory: `.`
- Start command: none

## Assets
All website visuals are bundled locally in `/images/` as optimized WebP files. They are concept artwork for the redesign and should be replaced with practice-approved photography before a live client launch.

## Forms
Forms intentionally do not transmit patient information. They only display a local confirmation message. A live launch should connect the forms to the practice's approved secure appointment workflow.

## Final verification
Before launch, confirm business copy, testimonials, credentials, hours, financing information, photography permissions and the appointment workflow directly with the practice.
